# Taxonomía de Bloom revisada

Bloom (1956) clasificó objetivos de aprendizaje en niveles de complejidad. Anderson y Krathwohl (2001) la revisaron: los niveles pasaron a **verbos**, se intercambiaron los dos superiores (*Crear* quedó arriba) y se agregó una segunda dimensión: el **tipo de conocimiento**.

## Dimensión del proceso cognitivo (de menor a mayor)

| Nivel | Qué implica | Verbos para objetivos y consignas | Producto escrito típico |
|---|---|---|---|
| 1. **Recordar** | Recuperar información | definir, enumerar, nombrar, reconocer, listar, citar | Glosario, lista de conceptos |
| 2. **Comprender** | Construir significado | explicar, describir, resumir, parafrasear, ejemplificar, clasificar, interpretar, comparar (simple) | Resumen, marco conceptual, divulgación |
| 3. **Aplicar** | Usar un procedimiento | aplicar, calcular, demostrar, ejecutar, implementar, resolver, utilizar | Informe de laboratorio, caso práctico |
| 4. **Analizar** | Separar en partes y relacionarlas | analizar, contrastar, diferenciar, examinar, organizar, relacionar, categorizar, inferir, identificar causas | Marco teórico crítico, matriz comparativa, análisis de resultados |
| 5. **Evaluar** | Juzgar con criterios | evaluar, valorar, justificar, argumentar, criticar, verificar, validar, determinar, priorizar | Ensayo argumentativo, discusión, pruebas de usabilidad |
| 6. **Crear** | Producir algo nuevo y coherente | diseñar, desarrollar, elaborar, formular, proponer, planificar, construir, producir | Proyecto tecnológico, propuesta, prototipo |

## Dimensión del conocimiento
| Tipo | Ejemplo |
|---|---|
| Factual | Datos, terminología ("el abstencionismo juvenil fue 37,4 % en 2018") |
| Conceptual | Teorías, modelos, clasificaciones ("acción conectiva") |
| Procedimental | Métodos, técnicas ("cómo aplicar una encuesta") |
| Metacognitivo | Conciencia del propio aprendizaje ("qué estrategia de revisión me funciona") |

Un objetivo se ubica cruzando ambas: *"Evaluar (proceso) la usabilidad de la app con base en criterios de Nielsen (conocimiento conceptual)"*.

## Cómo usar Bloom en esta base
1. **Redactar objetivos** ([../04-secciones/objetivos.md](../04-secciones/objetivos.md)): el general suele estar en *Analizar*, *Evaluar* o *Crear*; los específicos escalan (p. ej., Analizar → Evaluar → Crear → Evaluar).
2. **Leer la consigna del docente**: el verbo dice qué nivel se espera. "Describa" ≠ "Analice" ≠ "Evalúe". Un trabajo que solo describe cuando se pidió analizar pierde puntos aunque esté bien escrito.
3. **Autoevaluar el texto**: marcá cada párrafo del marco teórico o la discusión con su nivel. Si casi todo es *Recordar/Comprender*, falta análisis propio.
4. **Preguntas de autoevaluación** para comprobar que el texto cubre todos los niveles pedidos (ver abajo).
5. **Rúbricas**: el revisor puede puntuar "profundidad cognitiva" según el nivel dominante.

## Preguntas de autoevaluación por nivel
| Nivel | Pregunta |
|---|---|
| Recordar | ¿Qué es la turistificación? |
| Comprender | ¿Por qué la turistificación afecta a los comercios locales? |
| Aplicar | ¿Cómo se aplicó la encuesta y a quién? |
| Analizar | ¿Qué diferencias hay entre su solución y Odoo? |
| Evaluar | ¿Qué tan efectiva fue la aplicación según las pruebas? ¿Qué limitaciones tiene? |
| Crear | ¿Cómo mejorarían la solución para otra provincia? |

## Otros dominios (mención)
Bloom también describió el dominio afectivo (Krathwohl et al., 1964) y otros autores el psicomotor. Para trabajos escritos se usa casi siempre el cognitivo.
