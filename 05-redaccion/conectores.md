# Conectores y marcadores

| Función | Conectores |
|---|---|
| Agregar | además, asimismo, del mismo modo, igualmente, por otra parte, a su vez |
| Contrastar | sin embargo, no obstante, por el contrario, en cambio, aun así, si bien… |
| Causa | debido a, ya que, puesto que, dado que, a causa de |
| Consecuencia | por lo tanto, por consiguiente, en consecuencia, de ahí que, así pues |
| Ejemplificar | por ejemplo, tal es el caso de, como muestra, específicamente |
| Aclarar | es decir, o sea, en otras palabras, dicho de otro modo |
| Ordenar | en primer lugar, en segundo lugar, posteriormente, finalmente, por último |
| Condición | siempre que, en caso de que, a menos que |
| Finalidad | con el fin de, para que, con el propósito de |
| Énfasis | en efecto, cabe resaltar, sobre todo |
| Concluir | en síntesis, en conclusión, en suma, en definitiva |
| Introducir cita | según, de acuerdo con, como señala, para X (año), X (año) sostiene/afirma/plantea/advierte |

## Verbos para introducir autores (evitá repetir "dice")
afirma, sostiene, argumenta, plantea, advierte, señala, explica, define, propone, demuestra, concluye, cuestiona, reconoce, enfatiza, describe.

## Errores
- "En base a" → **con base en** / **a partir de**.
- "A nivel de" (no espacial) → **en**, **en cuanto a**.
- "Mediante a" → **mediante**.
- Abusar de "además" y "por otra parte" al inicio de cada párrafo.
