# Agro, ambiente, deporte, carreras técnicas y oficios

En carreras técnicas y oficios el trabajo escrito suele ser **práctico**: informe de práctica, manual de procedimiento, ficha técnica, bitácora, plan de negocio. APA 7 por defecto, lenguaje claro, pasos numerados, seguridad primero.

## Agro y ambiente
| Materia | Trabajos típicos | Claves propias |
|---|---|---|
| Agronomía | Informe de ensayo de campo, plan de manejo | Diseño experimental, fertilización, plagas (nombres científicos) |
| Zootecnia / producción animal | Plan productivo, informe | Índices productivos, bienestar animal |
| Ingeniería forestal | Inventario forestal, plan de manejo | Parcelas, volumen, SINAC |
| Gestión ambiental | Diagnóstico, plan de gestión | Huella de carbono, ISO 14001 |
| Manejo de recursos naturales | Estudio de caso | Áreas protegidas, comunidades |
| Acuicultura / pesca | Plan productivo | Calidad del agua, INCOPESCA |
| Agroindustria | Diagrama de proceso, inocuidad | BPM, HACCP |
| Apicultura | Manual de manejo, informe | Sanidad apícola, polinización |
| Café / caficultura y catación | Informe de calidad, ficha de taza | Protocolo SCA, ICAFE |
| Enología / vitivinicultura | Ficha de cata, informe de elaboración | Variedades, proceso |
| Cervecería artesanal | Receta técnica, control de calidad | IBU, densidades, BJCP |
| Horticultura / jardinería / paisajismo | Plan de diseño, manual | Especies nativas |
| Floristería / arreglo floral | Portafolio, ficha técnica | Especies, conservación |
| Cetrería | Bitácora de manejo, informe | Bienestar animal, permisos de fauna |
