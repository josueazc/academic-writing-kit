# Ingenierías y tecnología

Convenciones comunes: **IEEE** o APA; títulos numerados (`numerar_titulos: true`); ecuaciones numeradas y variables definidas; unidades del SI; normas citadas con número (ISO, IEEE, INTECO, ASTM, NFPA); diagramas como figuras; código en anexos o repositorio citado.

| Materia | Estilo habitual | Trabajos típicos | Claves propias |
|---|---|---|---|
| Ingeniería civil | APA / ASCE | Informe técnico, memoria de cálculo, estudio de suelos | Código Sísmico de CR, planos, cargas |
| Ingeniería industrial | APA | Estudio de tiempos, distribución de planta, Lean/Six Sigma | Diagramas de proceso, indicadores |
| Ingeniería eléctrica | IEEE | Informe de laboratorio, diseño | Diagramas unifilares, normas NEC |
| Ingeniería electrónica | IEEE | Proyecto, diseño de circuito | Esquemáticos, simulaciones |
| Ingeniería mecánica | ASME / IEEE | Diseño, informe | Planos, tolerancias, CAD |
| Mecatrónica / robótica | IEEE | Proyecto, prototipo | Diagramas de control, firmware |
| Ingeniería química | ACS | Diseño de proceso, balance de materia y energía | Diagramas de flujo de proceso |
| Ingeniería ambiental | APA | Estudio de impacto, tratamiento de aguas | Legislación SETENA, indicadores |
| Ingeniería en sistemas / software | IEEE / APA | SRS, documento de diseño, proyecto aplicado, pruebas | UML, ISO/IEC 25010, historias de usuario |
| Ciencias de la computación | ACM / IEEE | Artículo, informe de algoritmo | Pseudocódigo, complejidad, benchmarks |
| Ciberseguridad | IEEE | Análisis de riesgos, informe de pentest | CVE, ISO 27001, divulgación responsable |
| Ciencia de datos / IA | IEEE / APA | Informe de modelo, model card | Métricas, sesgo, ética de datos |
| Telecomunicaciones / redes | IEEE | Diseño de red, informe | Topologías, RFC |
| Ingeniería biomédica | IEEE / Vancouver | Diseño de dispositivo | Normas IEC 60601, ética |
| Ingeniería agrícola | APA | Diseño de riego, informe | Suelos, clima |
| Ingeniería en materiales | IEEE / ACS | Informe | Ensayos mecánicos |
| Ingeniería aeroespacial | AIAA | Informe de diseño | Normas aeronáuticas |
| Ingeniería en minas / petróleo | SPE / APA | Informe técnico | Seguridad, impacto |
| Ingeniería topográfica / geomática | APA | Levantamiento, informe SIG | Sistemas de coordenadas (CRTM05) |
| Ingeniería en construcción | APA | Presupuesto, programación de obra | Gantt, ruta crítica |
| Arquitectura de software / DevOps | IEEE | Documento de arquitectura, ADR | C4, decisiones y alternativas |
| Diseño UX/UI | APA | Investigación de usuarios, caso de diseño | Personas, pruebas de usabilidad, heurísticas de Nielsen |

| Energías renovables | IEEE / APA | Estudio de factibilidad | Irradiación, LCOE |
