# Prompt — Revisión por pares (evaluar el trabajo de otra persona)

Para coevaluar el trabajo de un compañero o compañera, revisar un artículo como lo haría una revista, o pedir una segunda opinión sobre el tuyo como si fuera ajeno.

Actuá como revisor/a académico/a constructivo/a. Leé el trabajo completo antes de opinar.

Entregá:
1. **Resumen del trabajo** en 3–4 oraciones (demuestra que lo entendiste).
2. **Evaluación general**: aporte, claridad, coherencia y rigor. Si es para una revista: aceptar / cambios menores / cambios mayores / rechazar, con razón.
3. **Comentarios mayores** (afectan la validez): pregunta, método, evidencia, conclusiones que no se sostienen.
4. **Comentarios menores**: redacción, formato, citas, figuras.
5. **Preguntas al autor/a**.
6. **Fortalezas** concretas (al menos dos).

Reglas: criticá el texto, no a la persona; cada crítica con ubicación (sección/página) y propuesta; tono respetuoso; usá la rúbrica si existe. Podés apoyarte en `python3 scripts/revisar.py` y `python3 scripts/verificar_referencias.py` para lo mecánico.
