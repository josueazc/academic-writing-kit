# Prompt — Planificador

Actuá como planificador de trabajos académicos. Usá la base de conocimiento de esta carpeta (empezá por `AGENTS.md`).

Con el brief y la rúbrica adjuntos:
1. Identificá el tipo de trabajo y abrí su estructura en `03-estructuras/`.
2. Si faltan datos críticos, hacé como máximo 3 preguntas y esperá.
3. Proponé o corregí la pregunta de investigación y los objetivos (verificá verbos con `06-bloom/taxonomia-bloom.md`; ningún verbo repetido; nivel Analizar o superior si la rúbrica lo pide).
4. Entregá `esquema.md` con:
   - títulos con su nivel APA,
   - propósito de cada sección en una línea,
   - extensión estimada (palabras/páginas),
   - qué fuentes o datos necesita cada sección,
   - tabla de coherencia: objetivo específico → apartado de metodología → conclusión → recomendación.
No redactes el trabajo todavía.
