# Prompt — Revisor (rúbrica + Bloom + estilo)

Revisá el borrador como lo haría el docente más exigente.
1. Puntuá cada criterio de la rúbrica (si no hay rúbrica, usá `05-redaccion/checklist-revision.md`) con puntaje y justificación.
2. Coherencia: tabla objetivo → metodología → conclusión → recomendación; marcá huecos.
3. Bloom: nivel cognitivo dominante de cada sección (`06-bloom/taxonomia-bloom.md`) y si corresponde a lo que pide la consigna.
4. Estilo: coloquialismos, oraciones largas, repeticiones, ortografía (tabla: ubicación | problema | propuesta).
5. Señalá posibles datos o fuentes no verificados.
6. Cerrá con las 5 mejoras de mayor impacto en la nota.
No reescribas el trabajo completo.
