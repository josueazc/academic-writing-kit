# Cómo contribuir

¡Gracias! Esta base mejora con reglas de más instituciones y con correcciones.

## Qué aportar
- **Perfiles institucionales** nuevos en `01-formato/perfiles/<institucion>.md` (universidad, revista, empresa), con: fuente, interlineado, márgenes, portada, orden de secciones y la fuente de la regla (reglamento, rúbrica, plantilla oficial).
- **Estructuras** de otros tipos de trabajo en `03-estructuras/`.
- Correcciones de APA 7 con cita al manual o a apastyle.apa.org.
- Ejemplos **anonimizados** de errores reales.

## Reglas
- Español neutro; voseo o tuteo, pero consistente dentro de cada archivo.
- Cada nota con frontmatter (`tipo`, `tema`) y enlaces relativos Markdown (`[texto](ruta.md)`), que funcionan en GitHub y en Obsidian.
- **No subas trabajos completos, nombres de estudiantes ni datos personales.**
- Toda regla nueva necesita fuente; si es una costumbre local, decilo ("observado en…").
- Si cambiás una regla, actualizá `PROMPT-UNIVERSAL.md` cuando corresponda: es el resumen que usan los chats web.

## Flujo
1. Fork → rama → cambio → pull request con descripción breve y fuente.
2. Revisá enlaces rotos antes de enviar.
