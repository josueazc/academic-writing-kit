# Marco teórico

Reúne lo que ya se sabe del tema para sustentar el análisis. Es la sección más larga, pero **no** es un collage de copiar y pegar.

## Cómo construirlo
1. **Mapa de temas**: a partir de los objetivos, listá conceptos y dimensiones. Cada objetivo específico debe tener teoría que lo respalde.
2. **Orden**: general → particular (mundo → país → comunidad), o conceptual → contextual → legal → tecnológico.
3. **Por cada subtema**: definición citada → explicación con tus palabras → datos/ejemplos → relación con tu problema (1–2 oraciones de "puente").
4. **Diálogo entre autores**: "Mientras Castells (2012) plantea…, Reguillo (2017) agrega…".
5. **Cierre** de cada bloque: síntesis breve que conecte con el siguiente.

## Proporción recomendada
≈ 40 % citas/paráfrasis, ≈ 60 % análisis y conexión propia. Una página que sea solo citas encadenadas es un error.

## Fuentes
| Preferir | Usar con cuidado | Evitar como base |
|---|---|---|
| Artículos científicos, libros académicos, informes de instituciones (INEC, TSE, PNUD, OMS, ICT), leyes, tesis | Periódicos reconocidos, blogs de empresas expertas (Cloudflare, Red Hat) | Wikipedia, Brainly, Monografías.com, blogs anónimos, contenido generado por IA sin fuente |

Buscadores: Google Académico, SciELO, Redalyc, Dialnet, Latindex, repositorios de UCR/UNA/TEC/UNED (Kérwá, Repositorio TEC), Kimuk.

## Elementos útiles
- Glosario de conceptos (en el marco o en anexos).
- Tablas comparativas (competencia, tipos, ventajas/desventajas) con formato APA.
- Marco legal: ley, número y artículo concreto.
